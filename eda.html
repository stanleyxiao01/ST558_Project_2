Introduction

This report explores the Bank Marketing dataset which contains information about customers contacted during a direct marketing campgaign conducted by a Portuguese banking institution. The primary objective is to investigate how customer characteristics and campaign interactions relate to whether a customer subscribes to a term deposit.

The repsonse variable, ‘y’, records whether a customer subscribed to a term deposit.

The dataset was obtained from Kaggle: Banking Dataset (Marketing Targets), which is based on the UCI Bank Marketing dataset

Data Preparation

The analysis uses the cleaned dataset stored in ‘Dataset/bank_clean.csv’. Categorical variables are represented as factors to support frequency tables, grouped summaries, and visualizations.

## Introduction

This report explores the Bank Marketing dataset which contains information about customers contacted during a direct marketing campgaign conducted by a Portuguese banking institution. The primary objective is to investigate how customer characteristics and campaign interactions relate to whether a customer subscribes to a term deposit.

The repsonse variable, 'y', records whether a customer subscribed to a term deposit.

The dataset was obtained from [Kaggle: Banking Dataset (Marketing Targets)](https://www.kaggle.com/datasets/prakharrathi25/banking-dataset-marketing-targets), which is based on the [UCI Bank Marketing dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing)

## Data Preparation

```{r}
#| label: setup
#| include: false

# Load packages
library(ggplot2)
library(dplyr)
library(knitr)
library(tidyverse)

# Read both datasets
train <- read_delim("Dataset/train.csv", delim = ";")
test <- read_delim("Dataset/test.csv", delim = ";")

# Combine train and test datasets and remove duplicate rows
bank_data <- rbind(train, test)
bank_data <- unique(bank_data)

# Check for remaining duplicates
sum(duplicated(bank_data))

# Clean & format
bank_data <- bank_data |>
  mutate(across(where(is.character), as.factor))

# Save combined clean data for the Shiny app
write_csv(bank_data, "Dataset/bank_clean.csv")

# Convert categorical variables into factors
categorical_vars <- c(
  "job", "marital", "education", "default", "housing", "loan", "contact", "month", "poutcome","y"
)

bank_data[categorical_vars] <- lapply( bank_data[categorical_vars],factor)
```

The analysis uses the cleaned dataset stored in 'Dataset/bank_clean.csv'. Categorical variables are represented as factors to support frequency tables, grouped summaries, and visualizations.
