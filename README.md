# Bank Marketing Data Explorer

An interactive R Shiny application built to explore customer demographic, financial, and outreach data from direct bank marketing campaigns. 

## Project Objective

The goal of this project is to investigate how customer characteristics (such as age, job type, education level, and account balance) relate to direct marketing outcomes—specifically, whether a client decides to subscribe to a term deposit. Through interactive filtering, summary statistics, and dynamic visualizations, the app provides a straightforward platform to uncover key patterns and trends within the combined campaign dataset.

## Core Features (Work in Progress)

- **Data Filtering:** Dynamic sidebar controls allowing users to isolate client cohorts based on categorical factors and numerical ranges.
- **Data Inspection & Export:** An interactive data table with an export option to download filtered data subsets.
- **Exploratory Data Analysis:** Numerical summaries, contingency tables, and multivariate visualizations (histograms, boxplots, scatter plots, and heatmaps) to assess campaign drivers.
